## 1. Phase 5 (branch `phase-5`)

Decisions under **2026-09-24 — Phase 5** in `docs/decisions.md`; the contract is `docs/interop.md`.

### Built, by brief item
1. **Export** (`app/src/export/`, the new **Files** tab): region pack, GeoJSON and TopoJSON of the
   dissolved regions with dossier properties, KML (a folder per region with polygon and capital pin,
   dividing lines in their own folder), SVG (regions, labels, legend, scale bar, date stamp,
   attribution), PNG via canvas, and the Markdown dossiers.
2. **Import** (`app/src/import/`): a RegionPack is validated and its mesh version checked; from another
   mesh the user chooses re-fit (nearest cell centre, keeps edits) or regenerate (unedited only).
   GeoJSON and KML become a split by majority overlap, a snap layer, or the scope.
3. **Save and load:** an IndexedDB library in the Files tab, every call wrapped; file upload and
   download; the share link only for splits a link can reproduce, with the reason when not.
4. **`docs/interop.md`:** where packs live, the RegionPack v1 contract, versioning rules, and the
   twenty-line Leaflet snippet.
5. **Tests**, below.

The three presets moved to the top-level `packs/` as `<slug>.v1.json` (unchanged bytes); a Vite plugin
serves them in dev and copies them into the build. The Region panel and the Markdown both render
`dossier/fields.ts`, so they share one order; the panel gained the distance-to-capital fact.

### Problems found on the way
- **Zero-area spikes in exported polygons.** geojsonhint flagged five canada-26 regions: the cell
  topology stores a few edges as two identical arcs (one per cell), which walk as A→B→C→B→A "holes".
  Arcs used twice by a region are now interior, and rings with no area are dropped; both presets now
  pass geojsonhint with no messages.
- **KML re-import lost multi-part regions.** @tmcw/togeojson reads a MultiGeometry of several polygons
  as a GeometryCollection, which the template reader ignored. It now takes polygons from any of the
  three shapes.
- **New Vitest files need the node environment** to read repo files (`new URL` under jsdom is not a
  file URL); they parse XML and HTML with @xmldom/xmldom.
- **The interop test's second hover** found two tooltips: a synthetic mouseout does not close
  Leaflet's first one. The test now looks for the region's own label.
