# 2026-09-15 — Contract amendments and Phase 1 (pipeline and base mesh)

## Done
- **Contract amendments, PR #2 (merged):**
  - hex-string cell ids
  - `byteOrder: "le"` on column envelopes and file meta
  - a `kind`-based dtype rule
  - `AttrsFile` and `Topology` contracts
  - jsonschema validation of `data/build/`
  - an OSM basemap fallback
- **Phase 1 pipeline:**
  - `download.py` with https, arcgis, sdmx and manual fetchers
  - `mesh.py`, `attributes.py`, `polygons.py`
  - `checksums.py`: `make build` and `make verify`
  - `make_fixture.py`
  - pytest gate checks
- **App:** `src/data/loadMesh.ts`, tested on a 50-cell fixture. The full artefacts also load through it with Zod validation, and population sums to 36,991,981.
- **Artefacts:** 38,323 cells; 42 attribute columns; 8 layer files (3 boundary tiers); 5.29 MB total.

## Deviations (details in decisions.md)
- GC hosts block the Codespace, so sources use official services, NRCan mirrors, and pinned Internet Archive copies.
- GDP table 36-10-0402 is discontinued. Its replacement, 36-10-0711, is a manual download, so `gdp_estimate` is omitted for now.
- Native Land Digital is not fetched: its API terms forbid storing or redistributing the data.
- Mesh coverage comes from the Atlas of Canada 1:1M, not StatCan cartographic files, which drop the Great Lakes.
- `attrs.py` is renamed `attributes.py`: the old name shadows the `attrs` package that jsonschema needs.
- Layers are gzipped. Boundaries are one topology per tier.
- Rivers use Strahler order ≥ 7 on Canada1Water, not ≥ 5.
- `population_2016` spreads CSD totals with 2021 DA weights, because DA-level 2016 counts don't exist.
