# Contract examples

Generated by `make examples` (pipeline/make_examples.py) with the Python column writer. Do not
edit by hand. Both test suites load these files:

- **Vitest** (`app/src/schema/schema.test.ts`) parses them with the Zod contracts and decodes
  the Python-encoded columns.
- **pytest** (`pipeline/tests/test_artefact_schemas.py`, `test_columns.py`) validates them
  against `docs/schemas/*.schema.json` with jsonschema.

`column-vectors.json` holds values whose bytes differ between little- and big-endian; both
encoders must produce exactly the stored base64.

The cells are real H3 resolution-5 cells around Edmonton. Every attribute value (CD/CSD codes,
population, GDP, etc.) is made up.
